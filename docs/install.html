一鍵開啟 LINE

設定一次，之後點瀏覽器的擴充圖示，就會用 Edge 開啟 LINE。

  • 1

    開啟 PowerShell

    按 Windows 鍵，輸入文字 powershell，再按 Enter。

    可以直接打字輸入，或按下面按鈕複製後貼上。

  • 2

    執行安裝指令

    在 PowerShell 視窗按 Ctrl + V 貼上，再按 Enter。

    只需執行一次，跑完把視窗關掉即可，不用理它。

  • 3

    開始使用

    點瀏覽器右上角的擴充圖示（見右上角箭頭），LINE 就會在 Edge 開啟。

    提醒：LINE 會在 Edge 開啟，不是 Chrome。
