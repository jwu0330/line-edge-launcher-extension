🗑️ 解除安裝指令

如需移除，複製以下指令到 PowerShell 執行：

Remove-Item "$env:LOCALAPPDATA\LineOpenerPro" -Recurse -Force
reg delete "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.line.opener" /f
Write-Host "已解除安裝" -ForegroundColor Green

🚀 開始執行 LINE

安裝完成後，請使用以下方式開啟 LINE：

📱
點擊 Chrome 擴充功能圖示
在瀏覽器右上角找到 LINE Opener Pro 圖示並點擊
💡 使用說明：
1️⃣ 確認已完成安裝（執行上方的安裝指令）
2️⃣ 點擊瀏覽器右上角的擴充功能圖示
3️⃣ 系統會自動開啟 Edge 並啟動 LINE

⚠️ 如果執行失敗：
• 請確認已正確執行安裝指令
• 到 chrome://extensions/ 重新載入擴充程式
• 重新點擊擴充功能圖示
