一鍵開啟 LINE

設定一次，日後點擴充圖示即以 Edge 開啟 LINE

1

開啟終端機

複製下方按鈕 → 按 Win → 貼上 → Enter

2

執行安裝指令

複製下方按鈕 → 終端機 Ctrl+V → Enter

3

開始使用

點 Chrome 右上角擴充圖示，LINE 會在 Edge 開啟

提示：LINE 會在 Edge 開啟，不是 Chrome
📌 點這裡查看更多說明(指令內容 / Edge 提醒 / 解除安裝)

第一次開 Edge 若跳出視窗

  • 登入 / 用 Google 帳戶 → 不用登入,關掉
  • 設為預設瀏覽器 → 選「否」
  • 歡迎畫面 / 匯入資料 → 直接關掉
  • 要安裝 LINE 擴充時,請在 Edge 開啟連結安裝(不要在 Chrome 裝)

解除安裝

Remove-Item "$env:LOCALAPPDATA\LineOpenerPro" -Recurse -Force
reg delete "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.line.opener" /f
Write-Host "已解除安裝" -ForegroundColor Green
