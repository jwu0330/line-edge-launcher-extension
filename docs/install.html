📱 一鍵開啟 LINE

跟著 3 步驟做,設定一次就好

1

開啟「終端機」

按鍵盤 ⊞ Win + X,在跳出的選單點 「終端機」(或「Windows PowerShell」)。

畫面會出現一個深藍/黑色的文字視窗,這就是要用的地方。

2

貼上指令並執行

回到剛剛的深色視窗,按 Ctrl + V 貼上,再按 Enter。

看到綠色的 安裝完成 就成功了 ✅

▾ 想看指令內容(不看也沒關係) 
載入中...
3

開始使用

點 Chrome 右上角的 🧩 拼圖圖示,選 「Open LINE in Edge」。

系統就會自動打開 Edge 並啟動 LINE 🎉

⚠️ 第一次開 Edge 時,如果跳出視窗…

  • 「要不要登入 / 用 Google 帳戶」 → 不用登入,關掉或按「略過」
  • 「設為預設瀏覽器」 → 選「否」或直接關掉
  • 「歡迎畫面 / 匯入資料」 → 直接關掉

這些視窗都不影響 LINE 使用,關掉就好 🙂

🗑️ 不想用了?點我看「解除安裝」方法

和安裝一樣:開啟終端機 → 複製下面指令貼上 → 按 Enter。

Remove-Item "$env:LOCALAPPDATA\LineOpenerPro" -Recurse -Force
reg delete "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.line.opener" /f
Write-Host "已解除安裝" -ForegroundColor Green
